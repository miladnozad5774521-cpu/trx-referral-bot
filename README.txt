ربات زیرمجموعه‌گیری TRX

1) Python 3.10 یا بالاتر نصب کنید.
2) این پوشه را باز کنید.
3) اجرا:
   pip install -r requirements.txt

4) توکن ربات را به صورت متغیر محیطی تنظیم کنید:
   Windows PowerShell:
   $env:BOT_TOKEN="توکن_ربات"

   Linux/Termux:
   export BOT_TOKEN="توکن_ربات"

5) سپس:
   python bot.py

کانال:
@bitpin9

منطق فعلی:
- کاربر با /start یا لینک اختصاصی وارد می‌شود.
- عضویت در @bitpin9 بررسی می‌شود.
- پس از تأیید عضویت، اگر کاربر با لینک یک معرف آمده باشد، 0.5 TRX به موجودی معرف اضافه می‌شود.
- /referral لینک اختصاصی و آمار را نشان می‌دهد.
- /balance موجودی و تعداد زیرمجموعه را نشان می‌دهد.

نکته مهم:
این نسخه «موجودی داخلی» را ثبت می‌کند و هنوز انتقال واقعی TRX روی شبکه را انجام نمی‌دهد.
برای پرداخت واقعی، باید سیستم برداشت، حداقل برداشت، آدرس کیف پول و روش پرداخت/کیف پول امن اضافه شود.
